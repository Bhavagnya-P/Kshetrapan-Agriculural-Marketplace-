Kshetrapan - Agricultural Marketplace
Kshetrapan is a role-based, end-to-end e-commerce application designed to streamline agricultural trade by connecting Admins, Farmers, 
and Buyers on a single platform. Built using standard Java web technologies, the system features dedicated role-based dashboards, secure 
product cycles, and strict quality assurance testing at every stage.

🚀 Key Features
> Role-Based Workflows: Distinct interfaces and permissions tailored for Admin, Farmer, and Buyer roles.
> Core E-Commerce Engine: Secure authentication, comprehensive product catalog management (CRUD), shopping cart functionality, and
  sequential order processing.
> Simulated Payments: A built-in mock gateway to handle sandbox payment transactions securely.
> Community Tools: Native system modules for product ratings, user reviews, and an end-to-end complaint management ticketing workflow.

🛠️ Tech Stack
> Frontend: HTML5, CSS3, JavaScript, JSP (JavaServer Pages)
> Backend: Java (Servlets)
> Database: MySQL
> Server: Apache Tomcat

🧪 Quality Assurance & Testing
This project followed a rigorous test-driven approach during development. Each component was isolated and validated before feature 
integration:
> Positive Scenarios: Verified intended user flows (successful checkouts, correct role routing).
> Negative Scenarios: Validated input rejections, authorization guardrails, and error handling.
> Boundary Conditions: Evaluated edge limits on product inventory volumes and numerical transaction constraints.
